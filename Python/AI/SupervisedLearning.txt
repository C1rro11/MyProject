What is Supervised learning?

-Learning from the "answer"(label) that I provided.

From input(X) to output(Y).

for example: I provide many data of input(X) that the housing size. and the output is the price of the house.
Then, using supervised learning can learn from my data set and give a rough guess of a new input enter.

There are many example are using supervised learning:

input(X)   To           output(Y)

email                   spam?(0/1)
audio                   text transcript
English                 Spanish
ad, user info           click?(0/1)
image, radar info       position of car


Algorithm using for supervised learning:
- regression (predicts numbers, infinitely many possible outputs.)
- classification (only for categories / class)

Terminology:

notation :lowercase x = "input" variable / feature / input feature
          lowercase y = "output" variable / target variable
          lowercase m = total number of training example.
          (x,y) = a single example.
          (x^(i), y^(i)) = the ith training example. (a particular single example) 
          x^(i) != x^i

for multiple features:          
          n = number of input features
          vector x^(i) = the ith training example from 1...n features
          x_j = the jth feature.
          x_j^(i) = the ith training example of jth feature.

Workflow:
1: feed the training feature and target variable into the learning algorithm.
2: the supervised learning algorithm will produce some functions f. 
3: the target of function f is to put a input x and produce y hat(estimate/ prediction for y.)

To design a learning algorithm:(think)
1: how to represent a function f? / what is the net formula are we going to use to compute f. 

f_w,b(x) = wx + b.  (w,b are numbers, and those will affect the prediction of y.)

for Multiple feature (multiple linear regression):
f_w,b(x) = w1x1 + w2x2 + w3x3 + ....+ wnxn + b
         = vector(w) . vector(x) + b
